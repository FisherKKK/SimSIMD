# SimSIMD 整体架构与设计理念

> 本文是 SimSIMD v6.5.13 代码库讲解系列的第一篇，面向初学者，以"老师讲课"的方式细致解读。

---

## 一、SimSIMD 是什么？

SimSIMD 是一个**高性能向量相似度计算库**，用 C 语言写成，核心功能是计算两个向量之间的"距离"或"相似度"。

### 实际应用场景

你可以把它想象成"测量两段文字有多相似"的工具，只不过文字被转换成了数字向量。具体应用包括：

- **向量数据库**（如 Pinecone、Weaviate）：存储和查询 AI 生成的嵌入向量
- **推荐系统**：计算用户偏好向量之间的相似度
- **图像搜索**：用图像的向量表示进行以图搜图
- **自然语言处理**：计算语义相似度

## 二、整体目录结构

```
SimSIMD/
│
├── include/simsimd/          ← 核心库（纯头文件，最重要！）
│   ├── types.h               ← 类型定义、平台检测、宏
│   ├── simsimd.h             ← 主入口头文件，聚合所有模块
│   ├── spatial.h             ← L2距离、余弦距离
│   ├── dot.h                 ← 点积（内积）
│   ├── binary.h              ← Hamming距离、Jaccard系数
│   ├── probability.h         ← KL散度、JS散度
│   ├── sparse.h              ← 稀疏向量运算
│   ├── curved.h              ← 马氏距离、双线性型
│   ├── elementwise.h         ← 逐元素运算（FMA、加权求和）
│   └── geospatial.h          ← 地理坐标距离
│
├── c/
│   └── lib.c                 ← 动态分发的 C 实现（运行时选择最优算法）
│
├── python/
│   └── lib.c                 ← Python 扩展（纯 CPython API，无 PyBind11）
│
├── javascript/               ← Node.js / WebAssembly 绑定
├── rust/                     ← Rust FFI 绑定
├── golang/                   ← Go 语言绑定
├── swift/                    ← Swift 绑定
│
├── CMakeLists.txt            ← CMake 构建脚本
├── pyproject.toml            ← Python 包配置
└── VERSION                   ← 版本号文件（当前 6.5.13）
```

### 关键洞察：为什么是纯头文件？

`include/simsimd/` 里的所有 `.h` 文件既是"声明"也是"实现"。C 语言的**头文件库（Header-Only Library）**设计有以下优势：

- **无需预编译**：用户只需 `#include "simsimd.h"` 即可，不用链接 `.so` / `.dll`
- **内联优化**：编译器可以看到完整代码，做更激进的优化（如内联展开）
- **跨平台方便**：不同平台编译器自动选择最优的 SIMD 路径

## 三、核心设计哲学

### 3.1 多层后端架构（Multi-Backend Architecture）

这是 SimSIMD 最重要的设计思想。对于同一个功能（比如"计算余弦距离"），库提供了**多种实现**，对应不同的 CPU 能力：

```
同一个功能 cos（余弦距离）对 f32 类型的多种实现：

  simsimd_cos_f32_serial      ← 普通 C 代码，所有 CPU 都能跑
  simsimd_cos_f32_neon        ← ARM NEON，128位寄存器
  simsimd_cos_f32_sve         ← ARM SVE，可变长度寄存器
  simsimd_cos_f32_haswell     ← x86 AVX2，256位寄存器
  simsimd_cos_f32_skylake     ← x86 AVX512，512位寄存器
  simsimd_cos_f32_sapphire    ← x86 AVX512 + FP16，最新特性
```

**打比方**：这就像一个餐厅，同一道菜有"普通版"（适合所有人）、"升级版"（适合有特殊需求的顾客）、"豪华版"（最好的原材料），根据顾客的情况动态选择。

### 3.2 两种分发策略

**编译时分发（Compile-time Dispatch）**（默认）：
```c
// 编译时，编译器检查 __AVX2__ 宏是否存在
#if SIMSIMD_TARGET_HASWELL
    // 编译 AVX2 代码
#endif
```

**运行时分发（Runtime Dispatch）**（可选）：
```c
// 开启方式：#define SIMSIMD_DYNAMIC_DISPATCH 1
// 程序启动时探测 CPU 能力，缓存最优函数指针
```

### 3.3 函数命名规则

SimSIMD 的函数名非常规律，格式为：
```
simsimd_<metric>_<type>_<backend>
         ↑         ↑       ↑
       度量类型  数据类型  硬件后端
```

例子：
| 函数名 | 解释 |
|--------|------|
| `simsimd_cos_f32_neon` | 余弦距离，32位浮点，ARM NEON |
| `simsimd_l2sq_i8_haswell` | 平方欧氏距离，8位整数，AVX2 |
| `simsimd_dot_f16_sapphire` | 点积，16位浮点，Sapphire Rapids |
| `simsimd_hamming_b8_serial` | Hamming距离，位向量，串行实现 |

## 四、支持的度量（Metric）一览

```
simsimd.h 中定义的所有度量（simsimd_metric_kind_t 枚举）：

经典距离：
  dot / inner         → 内积（点积）：a·b = Σ(aᵢ × bᵢ)
  vdot                → 复数内积（含虚部）
  cos / cosine        → 余弦距离：1 - cos(θ) = 1 - (a·b)/(|a||b|)
  l2 / euclidean      → 欧氏距离：√Σ(aᵢ-bᵢ)²
  l2sq / sqeuclidean  → 平方欧氏距离：Σ(aᵢ-bᵢ)²（省去开方）

二进制距离：
  hamming / manhattan → Hamming 距离：不同位的数量
  jaccard / tanimoto  → Jaccard 系数：交集/并集

稀疏向量：
  intersect           → 集合交集大小
  spdot_counts        → 整数权重稀疏点积
  spdot_weights       → BF16权重稀疏点积

曲率空间：
  bilinear            → 双线性型：aᵀCb（C为度量张量）
  mahalanobis         → 马氏距离：√((a-b)ᵀ C⁻¹ (a-b))

概率分布：
  kl / kullback_leibler → KL散度：Σ p(x)·log(p(x)/q(x))
  js / jensen_shannon   → JS散度：(KL(p||m) + KL(q||m))/2

BLAS类运算：
  fma   → 融合乘加：r[i] = α·a[i]·b[i] + β·c[i]
  wsum  → 加权求和：r[i] = α·a[i] + β·b[i]
```

## 五、支持的数据类型

```
simsimd_datatype_t 枚举：

位类型：
  b8 / b1x8   → 每8位打包成1字节的位向量
  i4x2        → 每4位整数打包成字节（量化场景）

整数类型：
  i8   → 有符号8位整数（量化AI模型常用）
  u8   → 无符号8位整数
  i16  → 有符号16位整数
  u16  → 无符号16位整数（稀疏索引）
  u32  → 无符号32位整数（稀疏索引）

浮点类型：
  f16  → 16位半精度浮点（IEEE 754，AI推理常用）
  bf16 → Brain浮点（Google提出，PyTorch/TF常用）
  f32  → 32位单精度浮点（最常见）
  f64  → 64位双精度浮点（最精确）

复数类型：
  f16c / bf16c / f32c / f64c → 上述浮点的复数版本
```

## 六、支持的硬件平台

```
x86 平台（按发布年代）：
  Serial    → 普通标量代码，无SIMD
  Haswell   → Intel 2013年，AVX2 + FMA + F16C（256位）
  Skylake   → Intel 2015年，AVX512 基础集（512位）
  Ice Lake  → Intel 2019年，AVX512 + VNNI 整数加速
  Genoa     → AMD 2023年，AVX512 + BF16 脑浮点
  Sapphire  → Intel 2023年，AVX512 + FP16 半精度
  Turin     → AMD 2024年，AVX512 + VP2INTERSECT 稀疏运算
  Sierra    → 现代Intel，AVX2 + VNNI（效率核）

ARM 平台：
  NEON      → ARM v8基础，128位固定宽度
  NEON_F16  → NEON + 半精度浮点支持
  NEON_BF16 → NEON + 脑浮点支持
  NEON_I8   → NEON + 整数点积加速
  SVE       → 可变长度SIMD（128~2048位），Graviton3等
  SVE_F16   → SVE + 半精度
  SVE_BF16  → SVE + 脑浮点
  SVE2      → SVE升级版，Graviton4、Nvidia Grace
```

## 八、总结

SimSIMD 的整体设计可以用以下几点概括：

1. **一套接口，多种后端**：对外暴露统一的函数名，内部根据硬件能力选择最优实现
2. **头文件库设计**：零依赖，易集成，编译器友好
3. **规范的命名**：`simsimd_<metric>_<type>_<backend>` 让代码一目了然
4. **极致的覆盖面**：从最老的串行实现到最新的 AVX512-FP16，全部支持
5. **多语言绑定**：C 核心，Python/JS/Rust/Go/Swift 包装
