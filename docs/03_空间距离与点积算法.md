# SimSIMD 空间距离与点积算法深度解析

## 一、三大核心度量的数学基础

在深入代码之前，先理清楚三个最常用度量的数学定义：

### 1.1 点积（Dot Product）

```
dot(a, b) = Σᵢ aᵢ × bᵢ
           = a₁b₁ + a₂b₂ + ... + aₙbₙ
```

**几何意义**：两个向量在同方向上的"投影强度"。点积越大，两向量越"同向"。

### 1.2 余弦距离（Cosine Distance）

```
cos_similarity(a, b) = dot(a, b) / (|a| × |b|)
                     = Σ(aᵢbᵢ) / √(Σaᵢ²) × √(Σbᵢ²)

cos_distance(a, b) = 1 - cos_similarity(a, b)
```

**几何意义**：两向量夹角的余弦值。夹角为0时（完全同向），相似度=1，距离=0；夹角为90°时，距离=1。

**注意**：SimSIMD 计算的是**距离**（distance），不是相似度（similarity）！

### 1.3 欧氏距离（L2 Distance）

```
l2(a, b) = √(Σᵢ (aᵢ - bᵢ)²)
l2sq(a,b) =  Σᵢ (aᵢ - bᵢ)²  ← 平方版，省去开方
```

**几何意义**：两点在空间中的直线距离。

## 二、宏展开技术：C 语言的"模板编程"

SimSIMD 的串行实现使用了一个巧妙的**宏展开**技巧，用一套宏生成所有类型的函数，避免重复代码。

### 2.1 宏的定义

```c
// spatial.h 第 182-225 行

// 平方欧氏距离宏
#define SIMSIMD_MAKE_L2SQ(name, input_type, accumulator_type, load_and_convert) \
    SIMSIMD_PUBLIC void simsimd_l2sq_##input_type##_##name(                     \
        simsimd_##input_type##_t const *a,                                       \
        simsimd_##input_type##_t const *b,                                       \
        simsimd_size_t n,                                                        \
        simsimd_distance_t *result) {                                            \
        simsimd_##accumulator_type##_t d2 = 0;                                   \
        for (simsimd_size_t i = 0; i != n; ++i) {                               \
            simsimd_##accumulator_type##_t ai = load_and_convert(a + i);         \
            simsimd_##accumulator_type##_t bi = load_and_convert(b + i);         \
            d2 += (ai - bi) * (ai - bi);                                         \
        }                                                                        \
        *result = d2;                                                            \
    }

// 欧氏距离宏（调用平方版，再开方）
#define SIMSIMD_MAKE_L2(name, input_type, accumulator_type, load_and_convert) \
    SIMSIMD_PUBLIC void simsimd_l2_##input_type##_##name(                     \
        simsimd_##input_type##_t const *a,                                    \
        simsimd_##input_type##_t const *b,                                    \
        simsimd_size_t n,                                                      \
        simsimd_distance_t *result) {                                          \
        simsimd_l2sq_##input_type##_##name(a, b, n, result);                  \
        *result = SIMSIMD_SQRT(*result);                                       \
    }

// 余弦距离宏
#define SIMSIMD_MAKE_COS(name, input_type, accumulator_type, load_and_convert) \
    SIMSIMD_PUBLIC void simsimd_cos_##input_type##_##name(                     \
        simsimd_##input_type##_t const *a,                                     \
        simsimd_##input_type##_t const *b,                                     \
        simsimd_size_t n,                                                       \
        simsimd_distance_t *result) {                                           \
        simsimd_##accumulator_type##_t ab = 0, a2 = 0, b2 = 0;                 \
        for (simsimd_size_t i = 0; i != n; ++i) {                              \
            simsimd_##accumulator_type##_t ai = load_and_convert(a + i);        \
            simsimd_##accumulator_type##_t bi = load_and_convert(b + i);        \
            ab += ai * bi;   /* 点积 */                                         \
            a2 += ai * ai;   /* |a|² */                                         \
            b2 += bi * bi;   /* |b|² */                                         \
        }                                                                       \
        /* 处理零向量情况 */                                                    \
        if (a2 == 0 && b2 == 0) { *result = 0; }                               \
        else if (ab == 0) { *result = 1; }                                      \
        else {                                                                  \
            /* 距离 = 1 - ab / (√a2 × √b2) = 1 - ab × rsqrt(a2) × rsqrt(b2) */\
            simsimd_distance_t r = 1 - ab * SIMSIMD_RSQRT(a2) * SIMSIMD_RSQRT(b2); \
            *result = r > 0 ? r : 0;  /* 裁剪负值（数值误差可能导致） */         \
        }                                                                       \
    }
```

### 2.2 宏展开的调用

```c
// spatial.h 第 227-261 行

// f64：输入f64，用f64精度累加
SIMSIMD_MAKE_COS(serial, f64, f64, SIMSIMD_DEREFERENCE)  // → simsimd_cos_f64_serial
SIMSIMD_MAKE_L2SQ(serial, f64, f64, SIMSIMD_DEREFERENCE) // → simsimd_l2sq_f64_serial

// f32：输入f32，用f32精度累加
SIMSIMD_MAKE_COS(serial, f32, f32, SIMSIMD_DEREFERENCE)  // → simsimd_cos_f32_serial

// f16：输入f16，但用f32精度累加（避免精度丢失）
SIMSIMD_MAKE_COS(serial, f16, f32, SIMSIMD_F16_TO_F32)   // → simsimd_cos_f16_serial
//                              ↑          ↑
//                       累加器用f32    加载时转换为f32

// bf16：同样升精度到f32
SIMSIMD_MAKE_COS(serial, bf16, f32, SIMSIMD_BF16_TO_F32) // → simsimd_cos_bf16_serial

// i8：输入有符号8位整数，用i32累加（防止溢出）
SIMSIMD_MAKE_COS(serial, i8, i32, SIMSIMD_DEREFERENCE)   // → simsimd_cos_i8_serial

// accurate 变体：用f64做高精度计算
SIMSIMD_MAKE_COS(accurate, f32, f64, SIMSIMD_DEREFERENCE) // → simsimd_cos_f32_accurate
```

### 2.3 宏展开的作用

`##` 是 C 预处理器的"粘贴"操作符。例如：

```c
// 调用：
SIMSIMD_MAKE_COS(serial, f32, f32, SIMSIMD_DEREFERENCE)

// 展开后等效于手写：
SIMSIMD_PUBLIC void simsimd_cos_f32_serial(
    simsimd_f32_t const *a,
    simsimd_f32_t const *b,
    simsimd_size_t n,
    simsimd_distance_t *result) {
    simsimd_f32_t ab = 0, a2 = 0, b2 = 0;
    for (simsimd_size_t i = 0; i != n; ++i) {
        simsimd_f32_t ai = *(a + i);  // SIMSIMD_DEREFERENCE 展开
        simsimd_f32_t bi = *(b + i);
        ab += ai * bi;
        a2 += ai * ai;
        b2 += bi * bi;
    }
    // ... 后续处理
}
```

**这个技术叫做"X宏"或"代码生成宏"**。优点是：
- 改一次宏定义，所有类型的实现都跟着更新
- 不会因为复制粘贴引入 bug
- 类似 C++ 的模板，但只用 C 语言实现

## 三、余弦距离的关键优化：RSQRT

注意宏中的关键行：
```c
simsimd_distance_t r = 1 - ab * SIMSIMD_RSQRT(a2) * SIMSIMD_RSQRT(b2);
```

正常计算 `1/√x` 需要：
1. 计算 `√x`（开方，很慢）
2. 计算 `1/√x`（除法，也慢）

SimSIMD 使用 `RSQRT`（Reciprocal Square Root，倒数平方根）：

- x86 上：用 `_mm_rsqrt_ps`（SSE）或 `_mm256_rsqrt_ps`（AVX2）指令，**一条指令**完成近似计算
- ARM 上：用 `vrsqrteq_f32`（NEON）指令
- 精度：约12-14位有效位（比标准 `sqrt` 略低，但对相似度计算足够用）

**打比方**：就像估算"一张A4纸能装多少字"——精确计算需要量纸、数字，但估算（"大概2000字"）对大多数场景够用，且快得多。

## 四、ARM NEON 的向量化实现解析

让我们逐行分析 `simsimd_l2sq_f32_neon`（spatial.h 第 323-338 行）：

```c
SIMSIMD_PUBLIC void simsimd_l2sq_f32_neon(
    simsimd_f32_t const *a,
    simsimd_f32_t const *b,
    simsimd_size_t n,
    simsimd_distance_t *result) {

    // 初始化一个 128 位寄存器，包含 4 个 f32，全部置 0
    // float32x4_t 就是 "4个float32放在一起"
    float32x4_t sum_vec = vdupq_n_f32(0);

    simsimd_size_t i = 0;

    // 主循环：每次处理 4 个元素（128位 / 32位 = 4）
    for (; i + 4 <= n; i += 4) {
        // vld1q_f32：从内存加载 4 个 float32 到 NEON 寄存器
        float32x4_t a_vec = vld1q_f32(a + i);
        float32x4_t b_vec = vld1q_f32(b + i);

        // vsubq_f32：向量减法，同时计算 4 个 (a[i]-b[i])
        float32x4_t diff_vec = vsubq_f32(a_vec, b_vec);

        // vfmaq_f32：融合乘加（Fused Multiply-Add）
        // sum_vec = sum_vec + diff_vec * diff_vec（同时计算4个）
        sum_vec = vfmaq_f32(sum_vec, diff_vec, diff_vec);
    }

    // vaddvq_f32：水平求和，把寄存器里4个float加在一起
    simsimd_f32_t sum = vaddvq_f32(sum_vec);

    // 尾部处理：处理不足4个的剩余元素（普通标量代码）
    for (; i < n; ++i) {
        simsimd_f32_t diff = a[i] - b[i];
        sum += diff * diff;
    }

    *result = sum;
}
```

### 关键 NEON Intrinsic 解释

| Intrinsic | 操作 | 处理数量 |
|-----------|------|---------|
| `vdupq_n_f32(0)` | 创建全零向量 | 4个f32 |
| `vld1q_f32(ptr)` | 从内存加载 | 4个f32 |
| `vsubq_f32(a, b)` | 向量减法 a-b | 4个f32 |
| `vfmaq_f32(acc, a, b)` | 融合乘加 acc + a×b | 4个f32 |
| `vaddvq_f32(v)` | 水平求和 | 4→1个f32 |

### 向量化的加速原理

```
非向量化（每次处理1个）：
  步骤1: diff1 = a[0] - b[0]; sum += diff1*diff1
  步骤2: diff2 = a[1] - b[1]; sum += diff2*diff2
  步骤3: diff3 = a[2] - b[2]; sum += diff3*diff3
  步骤4: diff4 = a[3] - b[3]; sum += diff4*diff4
  ← 需要4次循环迭代

向量化（每次处理4个）：
  步骤1: diff_vec = [a0-b0, a1-b1, a2-b2, a3-b3]  (vsubq_f32)
  步骤2: sum_vec  = sum_vec + diff_vec*diff_vec     (vfmaq_f32)
  ← 只需1次循环迭代！速度提升4倍
```

## 五、余弦距离的 NEON 实现

```c
// spatial.h 第 341-358 行
SIMSIMD_PUBLIC void simsimd_cos_f32_neon(
    simsimd_f32_t const *a,
    simsimd_f32_t const *b,
    simsimd_size_t n,
    simsimd_distance_t *result) {

    // 三个累加器：点积、|a|²、|b|²
    float32x4_t ab_vec = vdupq_n_f32(0);
    float32x4_t a2_vec = vdupq_n_f32(0);
    float32x4_t b2_vec = vdupq_n_f32(0);

    simsimd_size_t i = 0;
    for (; i + 4 <= n; i += 4) {
        float32x4_t a_vec = vld1q_f32(a + i);
        float32x4_t b_vec = vld1q_f32(b + i);

        ab_vec = vfmaq_f32(ab_vec, a_vec, b_vec);  // ab += a * b
        a2_vec = vfmaq_f32(a2_vec, a_vec, a_vec);  // a2 += a * a
        b2_vec = vfmaq_f32(b2_vec, b_vec, b_vec);  // b2 += b * b
    }

    // 水平求和
    simsimd_f32_t ab = vaddvq_f32(ab_vec);
    simsimd_f32_t a2 = vaddvq_f32(a2_vec);
    simsimd_f32_t b2 = vaddvq_f32(b2_vec);

    // 处理尾部
    for (; i < n; ++i) {
        simsimd_f32_t ai = a[i], bi = b[i];
        ab += ai * bi, a2 += ai * ai, b2 += bi * bi;
    }

    // 归一化：调用专门的归一化函数
    *result = _simsimd_cos_normalize_f64_neon(ab, a2, b2);
}
```

归一化函数用到了 Newton-Raphson 迭代提升 RSQRT 精度（spatial.h 第 300-315 行）：

```c
// 利用 Newton-Raphson 精化倒数平方根
float64x2_t rsqrts = vrsqrteq_f64(squares);
// 第一次迭代
rsqrts = vmulq_f64(rsqrts, vrsqrtsq_f64(vmulq_f64(squares, rsqrts), rsqrts));
// 第二次迭代（再精化一次）
rsqrts = vmulq_f64(rsqrts, vrsqrtsq_f64(vmulq_f64(squares, rsqrts), rsqrts));
```

**Newton-Raphson 迭代原理**：

如果 `x₀` 是 `1/√a` 的初始近似值，则迭代公式为：
```
xₙ₊₁ = xₙ × (3 - a × xₙ²) / 2
```
每迭代一次，精度约翻倍（位数加倍）。

## 六、点积：复数向量的处理

`dot.h` 不仅支持实数点积，还支持**复数向量**。复数点积的数学定义：

```
普通复数点积：dot(a, b) = Σ (aᵣ + iaᵢ)(bᵣ + ibᵢ) = Σ (aᵣbᵣ - aᵢbᵢ) + i(aᵣbᵢ + aᵢbᵣ)

共轭点积（vdot）：dot(a*, b) = Σ (aᵣ - iaᵢ)(bᵣ + ibᵢ) = Σ (aᵣbᵣ + aᵢbᵢ) + i(aᵣbᵢ - aᵢbᵣ)
```

在内存中，复数 `a + bi` 存储为相邻的两个值 `[a, b]`。

NEON 实现用了 `vld2_s16` 把交织存储的实部和虚部**分开加载**：

```c
// dot.h 第 465-476 行
// 交织加载：a_vec.val[0] = 实部, a_vec.val[1] = 虚部
int16x4x2_t a_vec = vld2_s16((short *)a_pairs);
int16x4x2_t b_vec = vld2_s16((short *)b_pairs);

// 转换为 f32
float32x4_t a_real_vec = vcvt_f32_f16(vreinterpret_f16_s16(a_vec.val[0]));
float32x4_t a_imag_vec = vcvt_f32_f16(vreinterpret_f16_s16(a_vec.val[1]));
float32x4_t b_real_vec = vcvt_f32_f16(vreinterpret_f16_s16(b_vec.val[0]));
float32x4_t b_imag_vec = vcvt_f32_f16(vreinterpret_f16_s16(b_vec.val[1]));

// 复数乘法的四个部分：
// 实部 = aᵣbᵣ - aᵢbᵢ
ab_real_vec = vfmaq_f32(ab_real_vec, a_real_vec, b_real_vec);  // += aᵣbᵣ
ab_real_vec = vfmsq_f32(ab_real_vec, a_imag_vec, b_imag_vec);  // -= aᵢbᵢ
// 虚部 = aᵣbᵢ + aᵢbᵣ
ab_imag_vec = vfmaq_f32(ab_imag_vec, a_real_vec, b_imag_vec);  // += aᵣbᵢ
ab_imag_vec = vfmaq_f32(ab_imag_vec, a_imag_vec, b_real_vec);  // += aᵢbᵣ
```

## 七、尾部处理：不足一个寄存器宽度怎么办

这是向量化编程的一个经典问题：如果向量长度不是 4（NEON 每次处理4个f32）的倍数，剩余的元素怎么处理？

### 方法1：尾部用标量循环（最常见）

```c
// 主循环：每次处理4个
for (; i + 4 <= n; i += 4) {
    /* SIMD 代码 */
}

// 尾部：剩余的用普通代码
for (; i < n; ++i) {
    simsimd_f32_t diff = a[i] - b[i];
    sum += diff * diff;
}
```

### 方法2：用 partial_load 填充（f16 的处理）

```c
// dot.h 第 416-428 行
SIMSIMD_INTERNAL float16x4_t _simsimd_partial_load_f16x4_neon(
    simsimd_f16_t const *x,
    simsimd_size_t n) {

    // 用 union 让同一块内存既能作为 float16x4_t（SIMD向量）也能作为数组访问
    union {
        float16x4_t vec;
        simsimd_f16_t scalars[4];
    } result;

    // 加载有效数据
    simsimd_size_t i = 0;
    for (; i < n; ++i) result.scalars[i] = x[i];
    // 填充0，保证不影响结果
    for (; i < 4; ++i) result.scalars[i] = 0;

    return result.vec;
}
```

### 方法3：AVX512 掩码操作（最优雅）

在 Skylake/Ice Lake 后端，用 `_mm512_mask_loadu_epi32` 带掩码加载，让 CPU 自动忽略超出范围的元素，完全消除尾部标量循环。

## 八、goto 的使用：罕见但合理

`dot.h` 中有一处使用了 `goto`（第 436-448 行）：

```c
// f16 NEON 点积的主循环结构
simsimd_dot_f16_neon_cycle:
    if (count_scalars < 4) {
        // 处理尾部
        a_vec = vcvt_f32_f16(_simsimd_partial_load_f16x4_neon(a_scalars, count_scalars));
        b_vec = vcvt_f32_f16(_simsimd_partial_load_f16x4_neon(b_scalars, count_scalars));
        count_scalars = 0;
    } else {
        // 正常加载
        a_vec = vcvt_f32_f16(vld1_f16(...));
        count_scalars -= 4;
    }
    ab_vec = vfmaq_f32(ab_vec, a_vec, b_vec);
    if (count_scalars) goto simsimd_dot_f16_neon_cycle;
```

这种 `goto` 用法实现了一个"do-while"风格的循环，将尾部处理合并进主循环，**减少了分支预测失败的开销**。

## 九、各变体的精度选择

| 函数变体 | 输入类型 | 累加精度 | 适用场景 |
|---------|---------|---------|---------|
| `*_serial` | 各类型 | 同输入类型 | 通用，速度与精度平衡 |
| `*_accurate` | f32/f16/bf16 | f64 | 需要高精度的场景 |
| `*_neon` / `*_haswell` | 各类型 | 通常升为 f32 | 硬件加速，速度最优 |

**重要设计决策**：即使输入是 f16 或 i8，累加器通常升级为 f32 或 i32。原因：
- f16 的范围是 ±65504，大量连续累加容易溢出
- i8 的范围是 -128~127，数百元素相乘累加必定溢出

## 十、小结

| 概念 | 技术 | 优势 |
|------|------|------|
| 宏展开 | `SIMSIMD_MAKE_*` 宏 + `##` 粘贴 | 一套代码生成所有类型实现 |
| RSQRT | 倒数平方根近似 | 比 sqrt+除法 快数倍 |
| Newton-Raphson | 迭代精化 | 将近似结果精度提升到实用水平 |
| NEON 向量化 | 128位寄存器处理4个f32 | 理论4倍加速 |
| 尾部处理 | 标量循环 / partial_load | 正确处理非对齐长度 |
| 累加器升精度 | f16→f32, i8→i32 | 防止数值溢出 |
| 复数点积 | vld2 分离实虚部 | 高效处理交织存储的复数 |
